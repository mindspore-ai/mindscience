# Simple Web Services Guide

Complete guide for accessing meteorological data through simple web service APIs with Siphon.

## Overview

Siphon's `siphon.simplewebservice` module provides access to various meteorological data sources through simple web service APIs, including upper air soundings, buoy observations, and climate data.

## Upper Air Data

### Wyoming Upper Air Archive

Access historical upper air sounding data from the University of Wyoming.

#### Basic Usage

```python
from datetime import datetime
from siphon.simplewebservice.wyoming import WyomingUpperAir

# Request data for specific station and time
df = WyomingUpperAir.request_data(datetime(2024, 1, 1, 0), 'DEN')

# View data
print(df.head())
print(df.columns)
```

#### Data Structure

```python
# DataFrame columns
print(df.columns)
# Index(['pressure', 'height', 'temperature', 'dewpoint', 'direction',
#        'speed', 'u_wind', 'v_wind', 'station', 'station_number',
#        'time', 'latitude', 'longitude', 'elevation', 'pw'],
#       dtype='object')

# Access units
print(df.units)
# {'pressure': 'hPa', 'height': 'meter', 'temperature': 'degC',
#  'dewpoint': 'degC', 'direction': 'degrees', 'speed': 'knot',
#  'u_wind': 'knot', 'v_wind': 'knot', 'station': None,
#  'station_number': None, 'time': None, 'latitude': 'degrees',
#  'longitude': 'degrees', 'elevation': 'meter', 'pw': 'millimeter'}
```

#### Working with Units

```python
from metpy.units import units

# Attach units to data
pressure = df['pressure'].values * units(df.units['pressure'])
temperature = df['temperature'].values * units(df.units['temperature'])
dewpoint = df['dewpoint'].values * units(df.units['dewpoint'])
u_wind = df['u_wind'].values * units(df.units['u_wind'])
v_wind = df['v_wind'].values * units(df.units['v_wind'])
```

#### Force Server Recalculation

```python
# Request server recalculate data (use sparingly)
df = WyomingUpperAir.request_data(
    datetime(2024, 1, 1, 0),
    'DEN',
    recalc=True
)
```

# International stations

### Iowa State Upper Air Archive

Access upper air sounding data from Iowa State University.

#### Single Station Request

```python
from datetime import datetime
from siphon.simplewebservice.iastate import IAStateUpperAir

# Request data for specific station
df = IAStateUpperAir.request_data(datetime(2024, 1, 1, 0), 'OUN')

# With interpolation for NaN values
df = IAStateUpperAir.request_data(
    datetime(2024, 1, 1, 0),
    'OUN',
    interp_nans=True
)
```

#### All Stations Request

```python
# Request data for all stations
df = IAStateUpperAir.request_all_data(datetime(2024, 1, 1, 0))

# Request specific pressure level
df = IAStateUpperAir.request_all_data(
    datetime(2024, 1, 1, 0),
    pressure=500  # 500 hPa
)
```

### IGRA2 Upper Air Archive

Access data from the Integrated Global Radiosonde Archive version 2.

#### Single Station Request

```python
from datetime import datetime
from siphon.simplewebservice.igra2 import IGRAUpperAir

# Request data (11-character IGRA2 station ID)
df = IGRAUpperAir.request_data(
    '724060-99999',  # Denver, CO
    datetime(2024401, 1, 0)
)
```

#### Time Range Request

```python
# Request data for date range
df = IGRAUpperAir.request_data(
    '724060-99999',
    [datetime(2024, 1, 1, 0), datetime(2024, 1, 31, 0)]
)
```

#### Finding IGRA2 Station IDs

IGRA2 station IDs are 11 characters. Use the IGRA2 station list or online tools to find station IDs.

## NDBC Buoy Data

### National Data Buoy Center

Access marine and buoy observations from NDBC.

#### Latest Observations

```python
from siphon.simplewebservice.ndbc import NDBC

# Get latest observations from all buoys
df = NDBC.latest_observations()

# View data
print(df.head())
print(df.columns)
```

#### Realtime Observations

```python
# Get realtime data from specific buoy
df = NDBC.realtime_observations('41001')

# Specify data type
df = NDBC.realtime_observations('41001', data_type='txt')
```

#### Raw Buoy Data

```python
# Get raw data string
raw_data = NDBC.raw_buoy_data('41001')

# Specify data type
raw_data = NDBC.raw_buoy_data('41001', data_type='cwind')
```

#### Available Data Types

```python
# Check available data types for buoy
types = NDBC.buoy_data_types('41001')
print(types)

# Common data types:
# 'txt' - Standard meteorological data
# 'drift' - Drifting buoy data
# 'cwind' - Continuous winds (10-minute average)
# 'spec' - Spectral wave summaries
# 'data_spec' - Raw spectral wave data
# 'swdir' - Spectral wave data (alpha1)
# 'swdir2' - Spectral wave data (alpha2)
# 'swr1' - Spectral wave data (r1)
# 'swr2' - Spectral wave data (r2)
# 'adcp' - Acoustic Doppler Current Profiler
# 'ocean' - Oceanographic data
# 'tide' - Tide data
# 'srad' - Solar radiation data
# 'dart' - Water column height
# 'supl' - Supplemental measurements
# 'rain' - Hourly rain data
```

## ACIS Climate Data

### Applied Climate Information System

Access climate data through the ACIS Web Services API.

#### Basic Request

```python
from siphon.simplewebservice.acis import acis_request

# Station metadata
params = {
    'sids': '724060',  # Station ID
    'elems': 'name,state,latitude,longitude,elevation'
}
result = acis_request('StnMeta', params)
print(result)
```

#### Station Data Request

```python
# Daily temperature data
params = {
    'sid': '724060',
    'sdate': '20240101',
    'edate': '20240131',
    'elems': [
        {'name': 'maxt'},
        {'name': 'mint'},
        {'name': 'avgt'}
    ]
}
result = acis_request('StnData', params)
print(result)
```

#### Multi-Station Data Request

```python
# Multiple stations
params = {
    'sids': '724060,724050,724040',
    'sdate': '20240101',
    'edate': '20240131',
    'elems': [{'name': 'maxt'}]
}
result = acis_request('MultiStnData', params)
print(result)
```

#### Grid Data Request

```python
# Gridded climate data
params = {
    'grid': '21',  # Grid ID
    'sdate': '20240101',
    'edate': '20240101',
    'elems': [{'name': 'maxt'}]
}
result = acis_request('GridData', params)
print(result)
```

#### ACIS Methods

```python
# StnMeta - Station metadata
result = acis_request('StnMeta', params)

# StnData - Single station data
result = acis_request('StnData', params)

# MultiStnData - Multiple station data
result = acis_request('MultiStnData', params)

# GridData - Gridded data
result = acis_request('GridData', params)

# General - General information
result = acis_request('General', params)
```

## Error Handling

### Network Errors

```python
from requests.exceptions import RequestException

try:
    df = WyomingUpperAir.request_data(datetime(2024, 1, 1, 0), 'DEN')
except RequestException as e:
    print(f"Network error: {e}")
```

### ACIS API Errors

```python
from siphon.simplewebservice.acis import AcisApiException

try:
    result = acis_request('StnData', params)
except AcisApiException as e:
    print(f"ACIS API error: {e}")
```

### No Data Available

```python
try:
    df = WyomingUpperAir.request_data(datetime(2024, 1, 1, 0), 'INVALID')
except ValueError as e:
    print(f"No data available: {e}")
```

## Best Practices

1. **Use appropriate data source** - Wyoming for historical, Iowa State for recent, IGRA2 for global
2. **Handle missing data** - Upper air data may not be available for all times/stations
3. **Check data types** - Verify NDBC data types before requesting
4. **Use station metadata** - Get station information before requesting data
5. **Rate limit requests** - Be respectful of API rate limits, especially for ACIS
6. **Validate station IDs** - Ensure station IDs are correct before requesting data
