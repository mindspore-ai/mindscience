mindscience.data.CSGIntersection
===================================

.. py:class:: mindscience.data.CSGIntersection(geom1, geom2, sampling_config=None)

    几何体交集的 CSG 对象定义。

    参数：
        - **geom1** (Geometry) - 几何体对象。
        - **geom2** (Geometry) - 要与geom1求交集的几何体对象。
        - **sampling_config** (SamplingConfig) - 采样配置，默认 ``None``。
