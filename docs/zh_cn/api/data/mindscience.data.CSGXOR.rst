mindscience.data.CSGXOR
==========================

.. py:class:: mindscience.data.CSGXOR(geom1, geom2, sampling_config=None)

    几何体异或 CSG 对象定义。

    参数：
        - **geom1** (Geometry) - 几何体对象。
        - **geom2** (Geometry) - 要与 `geom1` 求异或的几何体对象。
        - **sampling_config** (SamplingConfig) - 采样配置，默认 ``None``。
