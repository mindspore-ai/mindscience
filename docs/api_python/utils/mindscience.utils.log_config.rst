mindscience.utils.log_config
=======================

.. py:function:: mindscience.utils.log_config(log_dir='./logs', model_name="model", permission=0o644)

    配置日志。

    参数：
        - **log_dir** (str, optional) - 存放日志的目录。 默认值："./logs"。
        - **model_name** (str, optional) - 作为日志前缀的项目名称。 默认值："model"。
        - **permission** (int, optional) - 日志文件的权限。 默认值：``0o644``。
