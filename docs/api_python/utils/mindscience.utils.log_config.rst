mindscience.utils.log_config
=======================

.. py:function:: mindscience.utils.log_config(directory, log_name="model")

    日志配置。

    参数：
        - **directory** (str) - 存放日志的目录。
        - **log_name** (str, optional) - 作为日志前缀的项目名称。 默认值："model"。
        - **permission** (int, optional) - 日志文件权限，默认 ``0o644``。
